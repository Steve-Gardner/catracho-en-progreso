# Catracho en Progreso

Juego para practicar español hablando. Las palabras caen; diga la traducción en voz alta antes de que toquen el suelo.

- Funciona mejor en Chrome (computadora o Android). En iPhone el reconocimiento de voz es limitado; use el teclado.
- Instalar: Chrome/Edge "Instalar app"; iPhone: Compartir → Agregar a pantalla de inicio.
- El progreso se guarda en cada dispositivo (Ajustes → Exportar/Importar para moverlo).
- Actualizar: editar los archivos, `git push`; el sitio se actualiza en ~1 minuto. Subir `VERSION` en `sw.js` si cambia la lista de archivos.
